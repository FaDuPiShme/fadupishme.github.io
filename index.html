Первый год: дневник малыша

Дневник малыша для мамы и папы

  • Кормления: грудь с таймером, смесь, сцеженное; нормы для доношенных и недоношенных.
  • Сон, окна бодрствования, подгузники, прогулки, купание, выкладывание на животик.
  • Рост и вес с перцентилями ВОЗ, прививки по национальному календарю, лекарства с напоминаниями.
  • Белый шум, дождь и «шшш» для сна.
  • Общий дневник семьи через ваш Google Диск — зашифрованно, без наших серверов.
  • Сводка для педиатра в PDF.

Бесплатно, без платных функций. Не медицинское изделие: нормы справочные, решения — вместе с педиатром.

Использование Google Диска и безопасность

Для функции «Семейный дневник» приложение использует доступ к Google Drive API исключительно в области drive.file. Это позволяет сохранять зашифрованные копии записей на личном Google Диске пользователя для синхронизации между родителями без использования сторонних серверов. Приложение не передаёт личные данные разработчику или третьим лицам. Использование информации, полученной от Google API, полностью соответствует Google API Services User Data Policy, включая требования Limited Use.
